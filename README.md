# 🌸 AeroTask

A simple and elegant desktop task manager built with **Python** and **CustomTkinter**.

AeroTask helps you quickly add and manage daily tasks in a clean, modern interface.

## ✨ Features

- 📝 Add tasks easily
- ✅ Mark tasks as completed
- 🎨 Modern dark UI
- 💻 Built using CustomTkinter
- 🚀 Lightweight and fast
- 🖥️ Starts automatically with Windows (optional)

## 📦 Installation

1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/AeroTask.git
```

2. Install dependencies

```bash
pip install customtkinter
```

3. Run the application

```bash
python taskwidget.py
```
